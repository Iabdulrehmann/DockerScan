# Security Policy

## Reporting a vulnerability

Please report security issues privately to the project maintainer rather than posting exploit details, credentials, or sensitive image contents in a public issue.

If no private reporting channel is configured on the repository, open a minimal issue asking for a private contact method. Do not include the vulnerability details in that issue.

## Scope

DockerScan is an independent static image inspection project. It is not a replacement for vendor security advisories, a maintained vulnerability feed, container runtime protections, or a professional security review.
